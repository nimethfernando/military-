# USS LCS(L)(3)-102 "Yankee Dollar" — Landing Craft Support Museum Website

Modern naval museum website for the **USS LCS(L)(3)-102 ("Yankee Dollar")**, docked at Mare Island Naval Shipyard in Vallejo, California. Modeled after the architecture and visual direction of the **Intrepid Museum (`intrepidmuseum.org`)** while repurposing authentic archival photographs, history, and 501(c)(3) fundraising details from **`lcsmuseum.org`** and **`usslcs102.org`**.

## Project Structure

- [`index.html`](file:///d:/Freelancing/military-/index.html) — Complete standalone responsive website (can be previewed directly in any browser or deployed statically).
- [`css/styles.css`](file:///d:/Freelancing/military-/css/styles.css) — Intrepid-inspired high-contrast dark navy, slate, signal gold, and crimson design system.
- [`js/main.js`](file:///d:/Freelancing/military-/js/main.js) — Interactive controller for the 5-station Virtual Museum Deck Explorer, Donation Impact Tier Selector, Filterable Archival Photo Gallery, Lightbox Viewer, and Virtual Museum Portal Modal.
- [`assets/images/`](file:///d:/Freelancing/military-/assets/images) — Local backup of 19 authentic historical/restoration photos + the hero ship drone video (`LCS.mp4`) extracted from `lcsmuseum.org` and `usslcs102.org`.
- [`squarespace/custom-css.css`](file:///d:/Freelancing/military-/squarespace/custom-css.css) — Ready-to-paste stylesheet for **Squarespace 7.1 → Website Tools → Custom CSS**.
- [`squarespace/full-page-code-block.html`](file:///d:/Freelancing/military-/squarespace/full-page-code-block.html) — Self-contained HTML/CSS/JS package (with live HTTPS asset URLs) ready to paste into a **Squarespace 7.1 Code Block**.
- [`squarespace/SQUARESPACE_SETUP_GUIDE.md`](file:///d:/Freelancing/military-/squarespace/SQUARESPACE_SETUP_GUIDE.md) — Step-by-step instructions to deploy into a Squarespace 7.1 trial site in under 5 minutes and transfer ownership to the client.
